# Fitness Tracker App

## Overview

Fitness Tracker App is a simple web-based application that helps users record and monitor their daily fitness activities. Users can add workout details such as exercise type, duration, and calories burned. The application provides a summary dashboard and stores data locally in the browser.

## Features

* Add fitness activities
* Select exercise type from a dropdown menu
* Track workout duration
* Track calories burned
* View activity history
* Display total workouts completed
* Display total workout duration
* Display total calories burned
* Progress tracking using a progress bar
* Local storage support to save user data

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Start adding fitness activities.
